# 古典密码

关键词：古典密码 凯撒 caesar 维吉尼亚 vigenere 栅栏 railfence 培根 bacon 摩斯 morse 敲击码 tapcode 替换密码 置换密码

## ① 识别指纹

- 附件就是一段**纯文本**，没有文件类型可言
- 字符集高度受限：只有大写字母 / 只有小写 / 只有 `01` / 只有 `.` 和 `-` / 只有 emoji 或汉字
- 题干用词："解密"、"译文"、"密码学"、"老古董"、"我爷爷留给我的"
- 密文长度短（几十到几百字符），有或没有空格分组
- 题目名常直接写着：凯撒、维吉尼亚、栅栏、摩斯、培根、曲路、当铺、佛曰
- 分值通常很低，属于 crypto 的第一题

## ② 考什么

- 替换类：凯撒 / ROT13 / 仿射 / Atbash / 单表替换 / 维吉尼亚（多表替换）
- 置换类：栅栏 / 列置换 / 曲路 / 螺旋矩阵
- 编码伪装：摩斯 / 敲击码（tap code）/ 培根 / ADFGX / 猪圈密码 / 当铺密码 / 云影密码
- 文字游戏：佛曰（新佛曰）、与佛论禅、社会主义核心价值观编码、颜文字
- 通用手段：**词频分析**、已知明文攻击、IC（重合指数）
- 工具链：CyberChef、dCode.fr、quipqiup、Ciphey

## ③ 判断流程

1. **看字符集**，这是最快的分流：
   - 只有 `0` `1` → 跳 2
   - 只有 `.` `-` `/` 和空格 → **摩斯**，跳 6
   - 只有 `A` `B`（或两种字符交替出现，长度 5 的倍数）→ **培根**，跳 7
   - 只有数字（0–9）且成对出现 → **敲击码**，跳 8
   - 数字散落、每两个数字对应一个汉字 → **当铺密码**，跳 9
   - 只有大小写字母，看起来像人话的一部分 → 跳 3
   - 有汉字或 emoji → **文字游戏类**，跳 10
2. **二进制串**：按 8 位一组转 ASCII；不是 8 的倍数 → 按 7 位 / 5 位再试；都不是 → 试 `0/1` 当长/短解摩斯
3. **字母类先试凯撒全家桶**：26 个位移全跑一遍，肉眼扫一眼有没有明文
   - 直接出结果 → 结束
   - 没出 → 跳 4
4. **判断是置换还是替换**：
   - 字母频率分布**仍像英文**（E/T/A 突出）→ 是**置换**类，试栅栏 2–8 栏、列置换
   - 频率分布**被抹平**（各字母频次接近）→ 是**多表替换**，试维吉尼亚
5. **维吉尼亚**：先用 IC 估密钥长度，再逐列做凯撒；或者直接把密文丢进 dCode / 在线维吉尼亚破解器
6. **摩斯**：把 `-`/`.` 按空格切开逐个查表；分不清词边界时，把所有可能的分割都试一遍
7. **培根**：把 A/B（或任意两种符号）映射成二进制，5 位一组，`A=0 B=1`
8. **敲击码**：`1-5` 的五五方阵，`(行,列)` 查字母表，`0` 或 `6-9` 出现说明不是敲击码
9. **当铺密码**：把数字按规则还原成笔画数/汉字，常见于"数字变汉字"的题，用现成脚本解
10. **文字游戏类**：先认出是哪种（佛曰 / 与佛论禅 / 核心价值观 / 颜文字），直接搜"XX 在线解密"——这类题就是考你认不认识，不是考你推
11. **全都识别不出来**：把密文原封不动粘进 **CyberChef 的 Magic 模式**，它会自动尝试几十种编码组合；仍然不行 → 回第 1 条，换一个字符集视角重看（比如空格本身也是信息）

## ⑤ 常见坑

| 现象 | 实际原因 | 正确应对 |
|---|---|---|
| 凯撒 26 位移都不像话 | 不一定是纯字母，标点/空格也被一起移了 | 只移字母，标点原样保留 |
| 频率分析失效 | 密文太短，统计不显著 | 长度 < 50 时别做频率分析，直接试工具 |
| 栅栏解出来还是乱码 | 栏数不对，或方向反了（先加密方向搞反） | 1–10 栏全试，两种方向都试 |
| 摩斯解出来是一串没有空格的字母 | 词边界丢了 | 用摩斯解码器把"可能的分割"全部列出来再拼 |
| 培根解不出来 | 用的是 `a/b` 混在正文里，而不是显式的 A/B | 找出正文里两种不同字体的字符，或者大小写、斜体 |
| 汉字怎么都解不出 | 题目用的是"社会主义核心价值观编码"这类套壳 | 直接搜原文前几个字的特征去匹配编码器 |
| 解出来是 `flag{...}` 但提交错误 | 多套了一层编码 | 把结果再丢回 CyberChef 的 Magic |

## ⑥ 例题

**题目**：维吉尼亚密码（Vigenère）标准教学样例
**来源**：维基百科 Vigenère cipher 词条的经典示例，所有教科书通用

**题干**：给定密钥 `LEMON`，密文 `LXFOPVEFRNHR`，求明文。

**关键观察**：
- 密文是纯大写字母，长度 12
- 字母频率看不出 E/T 的优势 —— 这是**多表替换**的典型特征
- 题干直接给了密钥（CTF 里没给密钥时，密钥长度要靠 IC 或 Kasiski 估算）

**走了哪条链**：第 1 条（字符集=大写字母）→ 第 3 条（凯撒无效）→ 第 4 条（频率被抹平，判定多表替换）→ 第 5 条（逐列凯撒）。

**命令与输出**：

```python
def vigenere_decrypt(ct, key):
    k = [ord(c) - 65 for c in key.upper()]
    out = []
    for i, c in enumerate(ct):
        if c.isalpha():
            out.append(chr((ord(c.upper()) - 65 - k[i % len(k)]) % 26 + 65))
        else:
            out.append(c)
    return ''.join(out)

vigenere_decrypt('LXFOPVEFRNHR', 'LEMON')
# 'ATTACKATDAWN'
```

**结果**：明文 `ATTACKATDAWN`（"黎明时进攻"），这是维吉尼亚密码最著名的示例。

**怎么验证自己算对了**：把明文用同一个密钥加密回去，应该得到原密文。加解密互为逆运算，这一步能快速排除"密钥长度猜错"的可能。

::: tip 从这道题迁移出去
比赛里的维吉尼亚题通常**不给密钥**。此时第 5 条要展开成：
IC 计算 → 猜密钥长度 → 按长度切列 → 每列当凯撒破解 → 拼出密钥 → 解密。
如果密文短于 50 字符，别硬算，直接用 dCode 的维吉尼亚破解器。
:::
