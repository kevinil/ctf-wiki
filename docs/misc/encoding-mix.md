# 编码与古典杂烩

关键词：编码链 套娃 多层解码 base64 brainfuck ook jsfuck AAencode 与佛论禅 佛曰 社会主义核心价值观编码 零宽字符 兽音 颜文字 CyberChef Magic 解码 层层编码

> 这一页管的是**"这到底是什么编码，解套顺序是什么"**。
> 单一编码的原理和哈希攻击在 [Crypto · 编码与哈希基础](/crypto/encoding-hash)，这里不重复。

## ① 识别指纹

- 附件是一段纯文本，字符集古怪但**高度规整**
- 解一层出来还是乱码，再解一层才是人话 —— **套娃**是 Misc 的标志
- 出现成片的 `+` `-` `<` `>` `[` `]` —— 某种"编程语言"
- 出现成片的 `Ook.` `Ook?` / 大量 `[]()!+` / 大量日文假名或 emoji
- 出现"佛曰"、"如是我闻"、`─`、`♂` `♀` 之类的符号组合
- 一个字都看不懂但复制出来长度正常 —— 可能是**零宽字符**（肉眼看不见但实际占字节）
- 分值极低，通常是签到题

## ② 考什么

- **套娃顺序**：多层编码的剥离次序
- **怪语言族**：Brainfuck / Ook! / JSFuck / AAencode / JJencode / Jother / Malbolge
- **中文壳**：佛曰（新佛曰）/ 与佛论禅 / 社会主义核心价值观编码 / 兽音译者 / 颜文字加密
- **不可见字符**：零宽字符（`U+200B` `U+200C` `U+200D` `U+FEFF`）
- **非常规表示**：摩斯的长短换成任意两种字符、base 换成任意字符表
- CyberChef Magic 的边界：它能解常见组合，解不了自定义换表和怪语言

## ③ 判断流程

1. **先整段丢进 CyberChef 的 Magic 模式** —— 零成本，能自动试几十种组合；出了可读结果就直接结束
2. **Magic 失败 → 看字符集**（基础编码的分流规则见 [Crypto · 编码与哈希](/crypto/encoding-hash) 第 1 条）
3. **字符集里有成片特殊符号 → 查是不是怪语言**，对着这张表认：

   | 特征 | 大概是什么 |
   |---|---|
   | 只有 `+ - < > [ ] . ,` 八种符号 | **Brainfuck** |
   | 大量 `Ook.` `Ook?` `Ook!` | **Ook!** |
   | 只有 `[]()!+` 五种字符，极长 | **JSFuck** |
   | 大量 `ﾟωﾟﾉ` `(´∀｀)` | **AAencode** |
   | 全是 `$` 和 `_` 和十六进制 | **JJencode / Jother** |
   | 汉字「佛曰」「如是我闻」「即说咒曰」 | **佛曰 / 与佛论禅** |
   | 只有「富强民主文明和谐」这 12 个词 | **社会主义核心价值观编码** |
   | 只有 `嗷呜啊~` 之类的拟声词 | **兽音译者** |
   | 一堆 `(๑•̀ㅂ•́)و✧` 之类 | **颜文字加密** |

   命中 → 去搜对应在线解码器，**这类题就是考你认不认识**，不要自己硬写解释器
4. **表里都不命中，且文本"看起来是空的"** → 检查零宽字符：
   ```bash
   python -c "s=open('a.txt',encoding='utf-8').read();print([hex(ord(c)) for c in s][:40])"
   ```
   出现 `0x200b` / `0x200c` / `0x200d` / `0xfeff` → 按 0/1 映射后转 ASCII
5. **解出来一层，还是乱码** → 回到第 1 条，把**结果**再丢进 Magic；循环到可读为止（常见 3–5 层）
6. **某层解出来是二进制文件头**（`PK`、`\x89PNG`、`\x7fELF`）→ 不是编码题了，存成文件回 [题型总表](/map)
7. **以上全不成立** → 回第 2 条，考虑"字面之外"的信息：首字母、大小写、标点数量、空格数量、每行长度

## ⑤ 常见坑

| 现象 | 实际原因 | 正确应对 |
|---|---|---|
| Magic 解出来还是乱码 | 用了自定义换表或怪语言 | 转第 3 条查怪语言表 |
| 零宽字符一复制就没了 | 编辑器/浏览器吞掉不可见字符 | 用 `xxd` 或 Python 读原始字节，别复制粘贴 |
| 解出来 "flag" 但提交错误 | 还有一层没剥 | 把结果再丢回 Magic |
| 佛曰和与佛论禅分不清 | 两者是不同算法 | 都试一遍，前者是「佛曰」，后者是「与佛论禅」 |
| 社会主义核心价值观解出来是空的 | 用的是"加密"版本而非"编码"版本 | 换一个解码器试试，不同工具处理方式不同 |
| base64 解出中文乱码 | 源是 GBK 编码 | 解码后按 `gbk` 再解一次 |
| 看着像乱码其实不是编码 | 是加密（有密钥） | 回看题目有没有给 key / 附件脚本 |

## ⑥ 例题

**题目**：Brainfuck 解释执行
**来源**：`Brainfuck` 是 CTF Misc 里最常见的"怪语言"签到题；本题使用其最经典的 Hello World 程序（公开示例）

**题干**：给出一段由 `+ - < > [ ] . ,` 组成的字符串，要求输出它运行的结果。

```text
++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.
```

**关键观察**：
- 只有 8 种字符，且 `[` `]` 成对 —— Brainfuck 的标志
- 长度为 106，正好是 Hello World 程序的标准长度

**走了哪条链**：第 1 条（Magic 不一定能识别 BF）→ 第 3 条（命中怪语言表：只有 8 种符号 → Brainfuck）→ 直接解释执行。

**命令与输出**：

```python
code = "++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++."
tape = [0] * 30000
p = pc = 0
stack, jump = [], {}
for i, c in enumerate(code):
    if c == '[': stack.append(i)
    elif c == ']':
        j = stack.pop(); jump[i] = j; jump[j] = i
out = []
while pc < len(code):
    c = code[pc]
    if   c == '>': p += 1
    elif c == '<': p -= 1
    elif c == '+': tape[p] = (tape[p] + 1) % 256
    elif c == '-': tape[p] = (tape[p] - 1) % 256
    elif c == '.': out.append(chr(tape[p]))
    elif c == '[' and tape[p] == 0: pc = jump[pc]
    elif c == ']' and tape[p] != 0: pc = jump[pc]
    pc += 1
print(''.join(out))
```

输出：

```text
Hello World!
```

**结果**：`Hello World!`。

**为什么值得手写一遍**：Brainfuck 只有 8 个指令，`[` `]` 就是 `while`。写一次解释器只要 20 行，之后所有 BF 题都能自己解，不用依赖在线工具 —— 也顺手理解了"图灵完备的最小指令集"是什么样。

::: tip 给真实比赛的建议
签到题不要手写解释器。**先搜在线解码器**，30 秒搞定；手写解释器是给"没有网络 / 解码器不认"的场合留的后手。
:::
