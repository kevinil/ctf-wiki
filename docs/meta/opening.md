# 开场起手

关键词：开场起手 通用起手式 侦察 流程 拿到题目先做什么

> 每道题都必须走一遍的通用起手式。这一步做的不是"解",是"缩小搜索空间"。
> 目标是 **5 分钟内** 把题目从"未知"变成"三类候选之一"。

## 开场判断流程

1. **题干完整复制到本地笔记**，包括分值、通过率、提示（如果比赛平台能看到）—— 命中，继续
2. **建工作目录** `mkdir ~/chal-<名字> && cd $_`，附件全部放进去 —— 命中，继续
3. **对每个附件 `file`**，把输出贴到笔记里 —— 命中，进 [题型总表](/map) 第 1 条
4. **每个附件 `binwalk -e`**（图像/文档/压缩包/二进制都值得跑）—— 有输出说明有嵌套，进对应题型页
5. **全量 `strings` 落盘**，`grep` 关键词 `flag` `ctf` `{` `password` `key` —— 命中，基本就快结束了
6. **看题目名称**：名字里出现的协议名/工具名/谐音，80% 是故意给的 —— 命中，直接去搜该工具
7. 以上全做完还是一头雾水 → 进 [卡住怎么办](/meta/stuck) 第 1 条

## 起手式命令

```bash
# 工作目录 + 全量侦察，一次跑完
mkdir -p ~/chal && cd ~/chal
for f in *; do
  echo "=== $f ==="
  file "$f"
  binwalk "$f" 2>/dev/null | head -20
done > recon.txt 2>&1

# 全量 strings
for f in *; do strings -n 6 "$f" > "strings_$f.txt" 2>/dev/null; done
grep -iE 'flag|ctf\{|key|passw' strings_*.txt | head -40
```

## 拿到 flag 之后

1. 立刻记进笔记：**这题属于哪一类、命中判断流程第几条**
2. 如果这条链在题型页里**没有出现**，补进去 —— 这是这个站能长大的唯一方式
3. 如果这条链**判断错了**，把"看起来像 X 实际是 Y"记进该页的「常见坑」

## 起手式不该做的事

| 别做 | 原因 |
|---|---|
| 一上来就开 IDA / Burp 大工具 | 90% 的题用 `file` + `strings` + `binwalk` 就能定位方向 |
| 先读 writeup 再做题 | 会跳过"识别"这一步，而这正是最难练、最值钱的能力 |
| 附件直接甩进在线工具 | 有的题故意在内网、有的题目数据会泄题 |
| 在桌面根目录乱丢脚本 | 三天后你再也找不到哪份脚本属于哪道题 |
