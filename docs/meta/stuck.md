# 卡住怎么办

关键词：卡住 瓶颈 换思路 元流程 做不出来 自检

> 遇到瓶颈时用的元流程。**只在你已经把该方向的判断流程走完一遍之后**才启动。

## 卡住的元判断流程

1. **确认你走完了该方向的判断流程** —— 没走完就去走，别跳过
2. **换颗粒度重新分类**：把"这是一道 Web 题"降级成"这是一个 PHP 应用"，再降级成"这是一个文件读取原语"
3. **重读题干，逐字**：CTF 题干的每一个词通常都有用。找出你刚才扫过去的词（人名、版本号、路径、括号里的内容）
4. **看题目名称**，把这名字当搜索引擎关键词搜一次
5. **反推出题人**：看题目里出现的库/版本/报错指纹，判断出题人想考什么
6. **找同类题**：用题型页的「识别指纹」里的关键词 + `ctf writeup <关键词>` 搜索
7. **降级到暴力**：爆破、枚举、模糊测试 —— 能自动化的事情不要用脑子做
8. **放下 20 分钟**，回来重看
9. **看 hint**，再用 [题型总表](/map) 重走一遍第 1 条

## 四种"卡住"要对症下药

| 症状 | 真实原因 | 对策 |
|---|---|---|
| 方向都不对，每条链都走不通 | 识别错了 | 回 [题型总表](/map) 第 4 条，重新 `file`/`binwalk` |
| 方向对，但走不动 | 缺一个前置条件（缺泄露、缺权限、缺参数） | 找缺口：上一层的输出是什么？你还没拿到的那个值叫什么？ |
| 方向对，走到了尽头还是没 flag | flag 不在你以为的地方 | 扩大搜索面：全部附件、全部内存、全部流量，别只看你关注的那一块 |
| 明明快到了，就是差一点 | 工具/版本环境不匹配 | 换工具、换版本、换在线复现环境；用题目自带的 Docker 环境 |

## 卡住时的自检清单

- [ ] 我 `file` 过每一个附件了吗？包括"看起来没用"的那个
- [ ] 我跑过 `binwalk -e` 吗？
- [ ] 我把所有 `strings` 导出并全文搜过 `flag` 吗？
- [ ] 我读过题目**名字**吗？
- [ ] 我读过题干的**每一句**吗？
- [ ] 我看过平台上的 hint 和通过率吗？
- [ ] 我试过用题目里的确切关键词去搜吗？
- [ ] 我有没有在某个错误假设上已经卡了 30 分钟以上？

最后一条最重要：**卡 30 分钟没有新信息，就该换假设，不是继续深挖**。
